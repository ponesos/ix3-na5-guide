# 법률 · 콘텐츠 규칙

최종 수정: 2026-09-08  
법률 자문이 아니다. 배포 전에 필요하면 전문가에게 확인한다.

## 비공식

이 사이트는 BMW AG, BMW 코리아와 **무관**하다. BMW, iX3, Neue Klasse 등은 해당 권리자의 상표일 수 있다. 페이지 상단에 비공식 고지를 유지한다.

## 사실의 출처

제원·가격은 보도자료·공식 사이트 등 **공개 출처**와 날짜를 남긴다. 수치는 시장·트림·인증 기준이 바뀌면 즉시 고친다.

### 딜러·내부 교육 자료

- “딜러 사 내부 교육용”, CONFIDENTIAL, SECRET 표시 PDF는 **원본을 사이트·GitHub에 올리지 않는다.**
- 공개 JSON에는 제원·가격·품번처럼 고객 응대에 쓰는 사실만 요약하고, `sources`에 “로컬 PDF(비공개)”로 남긴다.
- 원본은 로컬 `.source-pdfs/`(gitignore)에만 보관한다.

## 액세서리

- 공식몰 **표시가**를 해당일·해당 국가 기준으로 인용한다.
- 한국 소비자가격, 관세, 공임, 재고가 아니다.
- 상품 사진·카탈로그 PDF를 무단 복제하지 않는다. 링크한다.
- 대량 자동 수집(스크래핑)은 하지 않는다.
- 사이트에 올리는 사진은 **오너·제보 촬영** 또는 사용 허가가 있는 것만. `site/images/accessories/` + JSON `image` 필드.

## 시승기

- 영상·기사 **전문을 옮기지 않는다.** 짧은 요약 + 원문 링크.
- 채널명·제목을 허위로 적지 않는다.
- 비방 목적의 왜곡 요약을 하지 않는다.

## 개인정보

VIN 전체, 번호판, 오너 실명·연락처를 사이트·공개 JSON·커밋에 올리지 않는다. 제보 메일에도 불필요한 개인정보를 받지 않도록 안내한다.

### 오픈채팅·카페 대화

- 대화 **전문·닉네임·프로필**을 사이트나 Git에 올리지 않는다. 원본은 `.source-pdfs/` 등 로컬만.
- 공개할 때는 **익명 요약(FAQ)** 만. 특정인을 식별할 수 있는 인용은 피한다.
- “커뮤니티 체감”임을 명시하고, 공식 안내와 충돌하면 공식을 따른다.

### VIN (수집용)

- 실제 VIN은 `secrets/vin.local.json`에만 둔다. 이 파일은 `.gitignore`로 제외한다.
- 예시만 `secrets/vin.local.example.json`에 둔다.
- 공식몰 적합성 확인·로컬 수집에만 쓰고, 공개 카탈로그에는 부품번호·출처 URL·가격만 남긴다.
- 채팅·이슈·스크린샷에 VIN 전체가 남지 않게 한다.
