## 어조 (전 차종 공통)

- 정보 전달 위주이되, **친근한 존댓말**(~예요 / ~해 주세요 / ~모아 두었어요).
- 딱딱한 공문서체·개발 메모체는 피한다.
- 금지: “~를 위한 사실 위주 정리”, “구매 검토와 초기 오너”, “자리만 있습니다”, API·스키마·수집 절차 노출.
- 선호: “국내 제원·트림·가격”, “유럽 정품 액세서리”, “준비 중이에요”.
- 비공식 고지(상단): 사이트 목적 한 줄(`meta.purposeKo`). 제조사명을 넣지 않는다.

## 제원·성능 라벨 (전 차종 공통)

공식 수치 블록 문구를 우선하고, UI에는 아래 짧은 라벨을 쓴다.

| 공식에서 흔한 문구 | 본 사이트 라벨 | JSON |
|--------------------|----------------|------|
| 1회 충전 주행 가능 거리 / 주행 가능 거리 | 주행 가능 거리 | `range.koreaCertified*` |
| … (WLTP 기준 …km) | 주행 가능 거리 (WLTP) | `range.wltpKm` |
| 복합 전비 | 복합 전비 | `battery.efficiency*` |
| 10분 충전 후 최대 주행 가능 거리 | 10분 충전 후 주행 가능 거리 | charging notes |
| 최대 출력 / kW (마력) | 최대 출력 | `performance.systemKw/Hp` |
| 가속력 (0-100km/h) | 가속력 (0–100 km/h) | `accel0to100Sec` |
| 안전 최고 속도 | 안전 최고 속도 | `topSpeedKmh` |

가격 카드: **가격대** = 전 트림 최저~최고 (`priceKrw` / min·max 집계). 단일가면 한 금액만.

## 파워트레인 · 트림 표기 (전 차종 공통 규칙)

1. **파워트레인은 공통 사양** → `markets.kr.powertrain` (및 히어로 킥커).
2. **트림은 짧은 약칭** → `trims[].nameKo` (SE, MSP, MSP Pro …).
3. **공식 긴 이름은 병기용** → `trims[].nameOfficialKo`.
4. 트림명에 파워트레인을 반복하지 않는다.

새 차종에서 약칭이 다르면(예: xLine, M Sport) 아래 차종 절에 매핑표를 추가한다.

## 면책 축약

- 가격: `부가세 포함, 개별소비세 N% 적용 기준. 옵션·할인·보조금에 따라 달라질 수 있습니다.`
- 액세서리: `유럽 표시가 기준. 국내 판매가·재고가 아닙니다.`
- 수치: 출처 기준일·국내 상품자료 우선을 `notesKo`에.
