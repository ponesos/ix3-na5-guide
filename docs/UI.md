# UI · 정보 구조

최종 수정: 2026-09-08

## 목표

모바일에서 카페 링크를 열었을 때 **3탭 안에** 원하는 사실(부품번호, 트림 가격, 시승 링크)에 닿는다.

## 사이트맵 (Phase 0)

| 경로 | 상태 | 독자 |
|------|------|------|
| `index.html` | 차량 개요 + 다음 행동 | 둘 다 |
| `accessories.html` | 유럽 액세서리 | 오너 |
| `tips.html` | 오너 FAQ | 오너 |
| `compare.html` | 자리표시 | 구매 검토 |
| `reviews.html` | 자리표시 | 구매 검토 |

전역 내비: 개요 / 액세서리 / 비교 / 시승기. 비공식 뱃지와 갱신일을 헤더 또는 띠에 둔다.

## 홈

- 한 줄: NA5, 국내 50 xDrive, 비공식
- 숫자: 시작가, 국내 항속, WLTP, 0–100, 800V
- 트림 표
- CTA: 액세서리로, 비교·시승기는 “준비 중”이어도 링크는 살아 있게

## 액세서리

- 필터: 카테고리, 시장(DE/UK/NL)
- 카드: (선택) 이미지, 한글명, 원문명, 품번, 현지가, 추정 원, 공식 링크, 장착 메모
- 하단: 한국 미판매 가능, VIN·딜러 확인, 추정 환율

이미지: `site/images/accessories/`에 파일을 두고 JSON `image` 필드로 연결. **오너·제보 촬영 권장.** 공식몰 핫링크·무단 복제는 하지 않음. 없으면 플레이스홀더.

## 비교 (제안, Phase 2)

행: 모델. 열: 가격대, 국내 항속, 급속·800V, 구동, 전장, 적재. 출처 열 또는 각주.

## 시승기 (제안, Phase 2)

카드: 제목, 채널, 날짜, 3–5줄, YouTube 링크. 스포일러성 주관은 “리뷰어 의견”으로 구분.

## 시각

- 모바일 우선, 최대 너비 약 72rem
- 시스템 폰트, 과한 그라데이션·장식 없음
- 본문 대비를 충분히 (어두운 글, 밝은 배경)
- 링크는 밑줄 또는 명확한 버튼. BMW 공식 CI를 복제하지 않음

## 이후 제안 (구현 전 이 문서에 적고 착수)

- 액세서리 “딜러 문의용” 품번 복사 버튼
- 트림별 기본 포함 여부 (확인된 것만)
- 충전 지도는 외부(환경부·브랜드 앱) 링크만
