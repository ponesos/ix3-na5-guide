## 목표

모바일 웹 **전용**. PC 레이아웃은 고려하지 않는다(필요 시 이후 확장).  
공유 링크를 열었을 때 **3탭 안**에 제원·가격·부품번호·FAQ에 도달한다.  
텍스트 벽 대신 **스토리 밴드 · 가로 스냅 카드 · 탭해서 펼치기**로 탐색하게 한다.

## 사이트맵

| 경로 | 내비 라벨 | 내용 |
|------|-----------|------|
| `index.html` / `index.html?v=` | 모델 정보 | 제원·트림·가격 (**기본 진입**, defaultVehicleId=iX3) |
| `vehicles.html` | 차종 | 차종 허브(스냅 카드) |
| `model.html?v=` | (리다이렉트) | `index.html?v=`로 이동 |
| `accessories.html?v=` | 액세서리 | 정품·서드파티 |
| `tips.html?v=` | FAQ | 질문 요약(답변 접힘) |
| `compare.html?v=` | 비교 | 준비 중 |
| `reviews.html?v=` | 시승기 | 유튜브 카드 레일 |
| `news.html?v=` | 뉴스 | 국내 보도 요약·원문 링크 |
| `community.html?v=` | 커뮤니티 | 해외 포럼 메타(최신/인기) |

헤더: 사이트명 · 비공식 · 데이터 기준일 · **현재 차종** + **슬림 섹션 카드 레일**(구 상단 텍스트 내비·하단 탐색 레일 통합).  
섹션 URL은 `?v=<vehicleId>`를 유지한다. 잘못된 id는 `vehicles.json`의 `defaultVehicleId`로 폴백.

## 시각 방향

- **모바일 단일 컬럼**. 다단 그리드·데스크톱 breakpoint 없음
- 다크 히어로 + 라이트 본문. 밴드마다 톤만 교차(`.story` / `.story-muted` / `.story-dark`)
- Pretendard. 공식 전용 서체·로고 미사용
- 액센트 블루는 CI 복제가 아닌 가독용
- 알약형 과다·크림/퍼플 테마 금지
- **가로 스냅 레일** (`.rail` / `.rail-card`): 카드 폭 `100vw − pad − peek`, `scroll-padding` + 트랙 스페이서로 첫·끝 카드가 잘리지 않게
- safe-area(`env(safe-area-inset-*)`) 반영
- **펼치기** (`details.expand`): FAQ 답변·트림 하이라이트·제원·출처·액세서리 링크
- 액세서리: **사진 영역 없음**(링크·가격 중심). 허가 사진만 예외. 필터로 정품/서드파티 구분
- 허브: 큰 스냅 카드로 차종 선택
- 스크롤 진입 시 `.reveal` (reduced-motion 존중)

## 모델 정보 (전 차종 동일 패턴)

1. 히어로: 큰 `displayNameKo` + 킥커 + 한 줄 소개  
2. 핵심 숫자: 가격대 / 국내 주행거리 / **WLTP 주행거리** / 가속 — **가로 스냅**  
3. 트림: 카드 레일(가격·휠 노출, 하이라이트는 펼침)  
4. 주요 제원 · 출처: 접힌 패널  

## 페이지별 노트

- FAQ: 하이라이트 레일 + Q·A 카드(답변 **펼침**). 분류 칩 sticky 가로 스크롤.
- 시승기·뉴스·커뮤니티·액세서리: 모바일 스냅 레일만.
- 시승기: `reviews.json` **게재일 최신순**. 채널·날짜·짧은 요약·영상 링크.
- 뉴스: `news.json` **게재일 최신순**. 매체·날짜·짧은 요약·원문 링크. 전문 전재 금지.
- 커뮤니티: 포럼 메타만. 본문·닉네임 금지.
- 네이버쇼핑 등은 개별 URL만 수동 등록. 검색 결과 페이지 일괄 수집 없음.
- 섹션 JSON이 없으면 “아직 준비 중” empty 상태.
